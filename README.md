# Spend Limit Tracker

![Spend Limit Tracker](images/v1-final-ui.png)

A browser-based budgeting application built with **HTML, CSS, and vanilla JavaScript** that helps users track monthly spending against a predefined budget.

The application stores all data locally using the browser's **Local Storage API**, allowing budgets and transactions to persist between sessions without requiring a backend or database.

---

## Features

- Set a monthly spending budget
- Add charges with the current date
- Automatically calculate the remaining budget
- View or hide charge history
- Delete individual charges
- Reset the month with confirmation
- Save all data using Local Storage

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

- GitHub

## Installation

1. Clone this repository.

```bash
git clone https://github.com/randystormes/spend-limit-tracker.git
```

2. Navigate to the project folder.

```bash
cd spend-limit-tracker
```

3. Open `index.html` in your browser.

No additional dependencies or installation are required.

---

## Usage

1. Enter your monthly budget.
2. Add charges as purchases are made.
3. Watch the remaining budget update automatically.
4. Show or hide your transaction history.
5. Reset the month when starting a new budget cycle.
